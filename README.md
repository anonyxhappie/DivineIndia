# 🛕 Divine India — The Temple Explorer

An immersive, interactive web experience for exploring India's most iconic temples through a dark-themed map interface with beautiful glassmorphic UI overlays and smooth animations.

## ✨ Features

- **Full-screen interactive map** — Dark CartoDB tiles with glowing custom temple markers
- **Glassmorphic sidebar** — Search by name, filter by deity & era
- **Darshan experience card** — Rich detail panel with animated images, sacred stories in elegant serif, and Google Maps links
- **Ambient audio** — Soft temple bells for immersion (mute/unmute toggle)
- **Smooth animations** — Framer Motion transitions throughout
- **Responsive** — Works on desktop and mobile

## 🛠 Tech Stack

| Layer | Technology |
|-------|-----------|
| Framework | React 18 |
| Build | Vite |
| Styling | Tailwind CSS |
| Map | React-Leaflet + CartoDB Dark Matter tiles |
| Animations | Framer Motion |
| Fonts | Playfair Display (serif) + Inter (sans) |

## 🚀 Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## 📦 Build for Production

```bash
npm run build
npm run preview
```
